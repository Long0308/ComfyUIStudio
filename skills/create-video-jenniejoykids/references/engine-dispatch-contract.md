# Engine dispatch contract — JennieJoy cartoon production

Updated 2026-10-27, Asia/Bangkok. Applies to `jenniejoy_cartoon_3d`. This is an execution checklist for the orchestrator, not a claim that a Markdown file launches workers. Use the existing film PLAN; do not create a competing board. The user's current cast, language, duration, authorizations and accepted assets override old episode examples.

## Start and resume: assign every lane before expensive inference

Read current film receipts, live queue, actual agents and hashes. Give every lane below a concrete live root/agent ID, task ID, permitted output folder, dependency, next action and acceptance test. A skill or capability name is a route and never counts as the owner. Dispatch all ready CPU/cloud/editorial lanes in the same orchestration wave. Root owns GPU scheduling, cross-lane acceptance and app publication unless explicitly delegated, and may execute authorized submissions/publication while retaining the single heavy-GPU owner. A missing specialized role does not remove its responsibility: use an available compatible role or root and record the change. A requested model must not be silently substituted.

Roles are examples of the current host capability, not permanent model pins: `router_gpt_6_astra` for independent script direction when available, `router_custom_oauth_anti_gemini_flash_high` for bounded editorial/audits, `worker` for implementation, specialist reviewers for changed code. Verify the configured route; report observed model only when exposed. The orchestrator uses the installed `astra-orchestrator` skill for actual dispatch/lifecycle tracking. Do not assume a particular role is always callable. If `harness-cli` stops at pre-code recall, dispatch via `codex exec -m <slug> -c model_reasoning_effort=high -s read-only|workspace-write -C <dir> --skip-git-repo-check --json -o <final.md>` through codex-router, using the requested route for the role (Gemini 3.8 Flash High = `custom/oauth-anti-gemini-flash-high`; DeepSeek = `opencode-go/deepseek-v4.1-flash`; never silently substitute another model). Four-layer recall is skipped on this path: record in the task receipt that the 4-proof harness receipt and four-layer recall are absent (see [harness-precode-recall-venv-missing.json](../error-db/harness-precode-recall-venv-missing.json)); verify the resolved model from the JSONL thread.

## Automatic event → next calls

1. **Film opened/resumed:** root reconciles state; script, audio, graphics/postproduction and publisher start together. Asset/Blender preparation starts only where missing. If the host permits only five children, combine voice/sub/music/SFX under one audio owner and HyperFrames/Remotion under one postproduction owner. Keep app with root. Every lane still has a recorded owner; a cap is not an excuse to postpone all finishing.
2. **Script/shot card saved:** dispatch voice for locked lines; subtitle design, music/SFX sourcing, icon lookup and intro/outro preparation proceed. Changed text invalidates dependent audio/lip/caption work, not unrelated assets.
3. **First complete image accepted:** import real PNG into the active episode's saved GUI/API workflow, record the Comfy GUI proof, and queue that shot's H3 when WAV is ready. Do not wait for the alternate hybrid route, full expression pack, all storyboards or final music. GUI presence alone does not prove Studio delivery.
4. **WAV completed:** verify exact bytes; notify subtitle, H3 and audio mix owners. Silence trims create new files/hashes with offsets; use the same selected take/offset in H3 and editorial. No unnoticed speech time-stretch or waveform replacement.
5. **H3 completed:** publisher records the real Comfy runtime ID and then separately proves Studio registration, HTTP media/hash readback and reopened display/playback. Before carry, reviewer inspects early, middle, late and decoded-end frames plus a normal-speed pass for spatial/depth drift, fence crossings, speaker lips and required action. Only then extract the exact last USED native frame for a declared carry; a motivated cut uses its own angle anchor. Do not use encoded approximate seeks or delivery-30fps frame indices for native-24fps carry.
6. **Motion accepted:** schedule bounded restoration, while Remotion places native preview and sound owner adjusts cues. Preserve raw native AV. Heavy GPU restoration/encoding is serialized; CPU component/timeline work continues.
7. **Restoration/component/stem arrives:** replace only the relevant timeline part by hash; render a scoped preview. Publisher updates the real job/artifact without calling it final Master acceptance.
8. **All required clips/audio/graphics ready:** render versioned Master at requested measured dimensions/FPS, inspect complete AV and listening/lips, register output/hash. Update skills with measured working recipe and failure recovery, not optimistic claims.
9. **Failure/report/interruption:** preserve receipt, inspect output and unknown job outcome before retry, keep independent work going, repair the critical dependency, reassign any released slot to the next ready task. Two repeated same-defect local failures invoke independent review plus authorized hybrid support.

## Required handoff schema

Each task receipt has `film_id`, `task_id`, `shot_id/global`, the live root/agent `owner`, `configured_route`, `requested_model`, `observed/resolved_model` or null, `input_paths_and_sha256`, `output_paths_and_sha256`, `status`, `runtime_id` (null is valid only with truthful reuse/external-tool provenance), `verification`, `acceptance_scope`, `next_consumer`, `next_action`. Image publication records Comfy GUI import, Studio registration, HTTP media/hash readback and reopened UI inspection separately. Track `prepared`, `queued`, `rendered_candidate`, `report_received`, `accepted` separately. Save native FPS/used frames and delivery FPS/timeline frames as different fields; changing sample/trim offsets invalidates lip/caption binding.

At each boundary, root checks lane coverage and updates PLAN: no lane has an empty owner; every ready lane is active or has an explicit current resource wait; every completed child is interrupted; every real media job is published or has a named publishing action. Reports and files alone do not establish audible/visual QA. This operating contract and reusable scripts improve the next run; editing SKILL.md is not model-weight retraining.
